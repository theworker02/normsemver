# normsemver

Norm and reshape semver text streams with deterministic transforms.

**Site:** https://theworker02.github.io/normsemver/

## Install / run

```bash
git clone https://github.com/theworker02/normsemver.git
cd normsemver
node src/cli.js
node --test
```
